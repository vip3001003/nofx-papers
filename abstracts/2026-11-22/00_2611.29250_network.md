# Hyperbolic network embedding via dimensional annealing and Barnes--Hut approximation

- **arXiv**: [2611.29250](https://arxiv.org/abs/2611.29250)
- **Date**: 2026-11-22
- **Category**: network
- **Authors**: Bukyoung Jhun, Gangmin Son, Hoyun Choi et al.
- **NOFX Relevance Score**: 0

## Abstract

Common features observed in complex networks from various domains can be explained by network geometry in hyperbolic space. Inferring the latent coordinates of nodes enables efficient navigation, link prediction, and geometric renormalization. However, the loss landscape of the hyperbolic model is extremely rugged due to the topological constraints of the low-dimensional embedding space. To overcome this, we introduce the dimensional annealing framework, which bypasses these constraints by introducing an auxiliary dimension. We show that dimensional annealing achieves higher-quality embeddings than existing energy-based embedding methods. Additionally, we incorporate the Barnes--Hut approximation for computational scalability.
