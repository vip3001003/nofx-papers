# Strong eigenstate thermalization in Singer-cycle Clifford circuits

- **arXiv**: [2611.22391](https://arxiv.org/abs/2611.22391)
- **Date**: 2026-11-17
- **Category**: complexity
- **Authors**: Naoto Tsuji
- **NOFX Relevance Score**: 0

## Abstract

Eigenstate thermalization hypothesis (ETH) provides a central framework for understanding thermalization in isolated quantum systems. Recently, the infinite-temperature ETH has been established for almost all Floquet eigenstates in linear feedback shift register quantum circuits. Here we introduce brickwork Clifford circuits with $L$ qubits where the induced transformation of Pauli operators is represented by an irreducible symplectic matrix over the finite field $\mathbb F_2$ of the maximal order $2^L+1$, known as a Singer cycle. For these Singer-cycle Clifford circuits, we prove a strong version of ETH: all Floquet eigenstates are thermal at infinite temperature without exceptions. We derive uniform bounds on both diagonal deviations from thermal expectation values and off-diagonal matrix elements of arbitrary observables supported on a fixed number of sites. The results indicate that long-time averages of observables approach the infinite-temperature values in the thermodynamic limit for arbitrary initial states. We also show that the temporal fluctuation of expectation values of observables is exponentially suppressed in the thermodynamic limit, implying that each observable remains close to the infinite-temperature value for almost all times.
