# 组合优化中比较神经求解器和启发式求解器的摊余效率阈值

- **arXiv**: [2605.14624](https://arxiv.org/abs/2605.14624)
- **日期**: 2026-05-14
- **分类**: bio_inspired
- **作者**: Sohaib Afifi
- **NOFX相关度**: 0

## 摘要

对神经组合优化求解器的一个常见批评是，考虑到在 GPU 上训练神经组合优化求解器的运行能源成本，它们的能源效率低于 CPU 元启发式算法。本文研究了从“训练成本高昂”到“神经求解器网络效率低下”的推理步骤，这正是批评实际上出错的地方。训练网络需要消耗大量固定的 GPU 能量；在每个实例上运行元启发式算法会消耗少量的 CPU 能量，只要部署了求解器，就会重复运行。在部署量确定之前，两者不可比较。我们将摊余效率阈值 (AET) 定义为部署量，高于该部署量，神经求解器在解决方案质量的明确约束下，在总能量或碳的启发式基线下达到平衡。我们表明，只要网络在每个实例中获胜，两个求解器之间的累积能量比就会趋向于严格低于 1 的常数，并且该限制不取决于如何测量训练成本。嵌入碳术语在两侧对称地摊销硬件制造。我们在 n=20 个客户的多任务 VRP (MTVRP) 环境中实例化该框架，涵盖 19 个问题变体和 5 个训练种子，并通过 PyVRP 使用 HGS 作为启发式基线。测得的交叉值接近 1.58 美元\乘以 10^5$ 部署实例；每个实例的比率为 0.41，反映出测试的实例规模适中。贡献在于框架、开放仪器和测量协议；较大问题规模下该比率的结构收敛留待未来的实证研究。
