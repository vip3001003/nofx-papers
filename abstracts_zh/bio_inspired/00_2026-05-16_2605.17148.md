# 使用 Manta Ray 优化和 Levy Flight 进行晶体结构预测的从头算能量景观的进化极限学习机

- **arXiv**: [2605.17148](https://arxiv.org/abs/2605.17148)
- **日期**: 2026-05-16
- **分类**: bio_inspired
- **作者**: Adrian Rubio-Solis
- **NOFX相关度**: 0

## 摘要

蝠鲼觅食优化算法 (MRFO) 已被证明是大量工程问题最优解决方案中强大的启发式策略。在本文中，建议使用 Levy Flight 对 MRFO 进行改进，用于训练基本模型为单层前馈网络（SLFN）的极限学习机（ELM）。所提出的方法（我们简称为“进化 EELM-MRFO-LF”）用于预测相对于二元系统中纯组分基态晶体结构的非松弛和松弛形成能化合物。 EELM-MRFO-LF 遵循传统进化 ELM 的学习过程，其中首先使用带有 LF 的 MRFO 来选择输入权重，然后应用 Moore-Penrose (MP) 广义逆来分析确定输出权重。 Levy Flight 轨迹的实现是为了增加 ELM 群体的多样性，防止过早收敛以及避免陷入局部最优的能力。在类似条件下，将建议的 EELM-MRFO-LF 的性能与其他著名的自然启发算法进行了比较。
