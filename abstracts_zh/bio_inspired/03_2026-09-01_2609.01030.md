# 网络价格提取：最先进的技术和自适应无浏览器实现

- **arXiv**: [2609.01030](https://arxiv.org/abs/2609.01030)
- **日期**: 2026-09-01
- **分类**: bio_inspired
- **作者**: Evgeniia Kositsyna, Jorge Lloret-Gazo
- **NOFX相关度**: 3

## 摘要

从网站中提取价格是电子商务中市场监控、价格比较和业务分析的关键任务。现有方法可大致分为四组，了解它们在准确性和可扩展性方面的权衡对于选择合适的提取策略至关重要。经典方法依赖于手动编写的包装器和来自标记页面的规则归纳，提供了很高的准确性，但对结构变化的适应能力较差，并且需要大量的维护工作。基于浏览器的方法使用 Selenium 和 Puppeteer 等工具来处理动态 JavaScript 内容，但会消耗大量计算资源且扩展性较差。无浏览器方法直接通过 HTTP 请求检索 HTML，可显着提高速度和成本，但依赖于针对特定站点校准的规则。基于机器学习和大型语言模型的方法提供了适应性，但需要训练数据和大量计算。我们的主要贡献是自适应无浏览器价格提取系统，该系统提高了网站之间结构差异的鲁棒性。我们实现了一个将 HTML 页面碎片与句法、语义和频率规则相结合的基线架构，并以两种方式对其进行了扩展：动态更新规则权重的贝叶斯方法和优化系统全局参数的遗传算法。这种混合方案将精度从 77.2% 提高到 87.3%，并且相对于基线，平均每页处理时间减少了约 14%，证实它是手动调整的无浏览器解决方案和资源密集型浏览器或基于 LLM 的方法的竞争替代方案，以低计算成本提供高提取精度。
