# 通过阈值符号排名进行基于 LLM 的源代码压缩

- **arXiv**: [2607.24192](https://arxiv.org/abs/2607.24192)
- **日期**: 2026-07-27
- **分类**: info_theory
- **作者**: Angelo Nardone, Paolo Ferragina
- **NOFX相关度**: 0

## 摘要

我们研究源代码的无损压缩问题，其动机是大型软件档案的存储需求，例如 Software Heritage (https://www.softwareheritage.org/)。通用压缩器（例如 zstd、bzip2）在压缩比和速度之间提供了良好的权衡，但无法利用源代码中固有的所有特殊规律。最近的方法利用香农符号排名框架内的大型语言模型（LLM），依赖于预测排名可以任意增长的方案。虽然可以有效地减少空间，但此设置会导致吞吐量显着下降，并且留下了是否有必要显式编码所有等级的问题。在这项工作中，我们介绍了基于 LLM 的压缩器，部署了两种新颖的符号排序变体，将预测绑定到顶级 $T$ 等级（$T=1$ 或 $63$），将超出阈值的符号存储为异常，并通过通用压缩器与等级流联合压缩。我们对 30 个 LLM 中基于 LLM 的源代码压缩进行了首次大规模评估，包括通用领域、代码专用和量化模型。我们的 $T$ 限制方法在压缩比（相对改进高达 37%）和压缩吞吐量（快 40%）方面均优于之前基于 LLM 的压缩器。与通用压缩器（例如 zstd、bzip2）相比，我们获得了高达 82% 的相对压缩增益，但速度较低，从而在压缩速度谱中提供了一个新的权衡点。我们还表明，这些收益在源代码上比在自然语言上更强，这表明了一个有趣的迹象，即源代码暴露了 LLM 捕获但被通用基于精确匹配的压缩器错过的规律性。最后，我们对提供理论和实践研究途径的开放问题进行评论。
