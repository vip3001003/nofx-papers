# 极值堆栈是速率无关泛函的最小充分统计量：柯尔莫哥洛夫复杂度表征

- **arXiv**: [2605.18885](https://arxiv.org/abs/2605.18885)
- **日期**: 2026-05-16
- **分类**: info_theory
- **作者**: Piotr Frydrych
- **NOFX相关度**: 1

## 摘要

我们证明，在柯尔莫哥洛夫复杂度的意义上，离散序列的极值堆栈是所有可计算的、因果的、速率无关泛函类的最小充分统计量。具体来说，我们建立 K(Pi_n) - O(1) <= K_R(u_{0:n}) <= K(Pi_n) + O(1)，其中 K_R(u_{0:n}) 是回答类 R 中每个查询的最短程序的长度，并且 O(1) 开销与序列长度 n 和堆栈深度 k 无关。充分性源自 Preisach 磁滞算子的经典擦除特性。极小性是通过有限指标族建立的，其速率独立性已得到明确验证。因此，任何保留完整 R 类的滞后驱动流压缩都必须保留至少 K(Pi_n) - O(1) 位；结果所暗示的基于堆栈的压缩算法具有柯尔莫哥洛夫最优性保证，而标准时间序列压缩方法均无法提供这种保证。
