# 独立三元随机变量之和的最大熵

- **arXiv**: [2605.11831](https://arxiv.org/abs/2605.11831)
- **日期**: 2026-05-12
- **分类**: info_theory
- **作者**: Mladen Kovačević
- **NOFX相关度**: 0

## 摘要

在三元情况下考虑并解决了最大化有限字母表上支持的独立随机变量之和的香农熵的经典问题。即建立如下定理：如果\(X_1,\ldots,X_n\)是取值在\(\{0,1,2\}\)中的独立随机变量，则当\(X_1,\ldots,X_{n-1}\)在\(\{0,2\}\)和概率质量上均匀时，\(S_n=X_1+\cdots+X_n\)的熵最大\(X_n\) 的函数由 \(\Prob(X_n=0) = \Prob(X_n=2) = w/2\)、\(\Prob(X_n=1) = 1-w\) 给出，其中 \(w = \big(1 + 2^{-H(B_n)+H(B_{n-1})}\big)^{-1}\) 和 \(B_m\sim \Bin(m,1/2)\)。该陈述可以被视为谢普-奥尔金-马特耶夫定理的三元字母表的扩展。该证明使用了埃尔米特-比勒定理、牛顿不等式以及用于超对数凹分布的于最大熵定理。
