# 混合压缩下的宽带近场信道估计：使用 OFDM 菲涅耳模型拟合跨子载波 KL 协方差

- **arXiv**: [2606.25101](https://arxiv.org/abs/2606.25101)
- **日期**: 2026-06-23
- **分类**: info_theory
- **作者**: Rıfat Volkan Şenyuva
- **NOFX相关度**: 0

## 摘要

我们考虑混合模数压缩下超大规模多输入多输出（XL-MIMO）阵列的宽带信道估计，其中通过比天线少得多的射频（RF）链来观察均匀线性阵列（ULA）。在带宽达到数百 MHz 的 28 GHz 载波频率下，标准窄带极域信道模型失败：近场菲涅尔曲率变得依赖于子载波，并且压缩观测破坏了窄带方法利用的每子载波空间协方差结构。我们提出了宽带跨子载波 Kullback-Leibler (WB-CL-KL) 估计器，它通过跨子载波 Kullback-Leibler (KL) 发散准则拟合正交频分复用 (OFDM) 子载波上的结构化菲涅尔协方差模型，直接从压缩样本协方差联合估计角度和范围，无需全阵列重建。我们还从 Slepian--Bangs 公式推导出宽带压缩域 Cramér-Rao 界 (CRB)——这种混合架构的性能下界，并将其在窄带界上的增益分解为 +27.093 dB 的数据分集分量和 +0.701 dB 的几何分集分量，在 B = 400 MHz 时总计为 +27.793 dB（命题 1 和 2）。在单路径视线状态下，WB-CL-KL 在信噪比 (SNR) = 10 dB（比率为 0.996）时达到 19.8 毫米的距离均方根误差，相对于 19.9 毫米的界限。在 3GPP 城市微 (UMi) 路径损耗和阴影衰落 SNR 分布下，它在中值部署 SNR 为 9.6 dB 时实现了 0.959 的边界比，表明在代表性部署点处进行近 CRB 操作，其中压缩域边界是在场景中值几何条件下评估的。
