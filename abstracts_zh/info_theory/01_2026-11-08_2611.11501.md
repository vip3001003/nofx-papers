# Compression of Sources with Memory and Private Random Access

- **arXiv**: [2611.11501](https://arxiv.org/abs/2611.11501)
- **日期**: 2026-11-08
- **分类**: info_theory
- **作者**: Venkat Chandar, Aslan Tchamkerten, Shashank Vatedka
- **NOFX相关度**: 1

## 摘要

Private local decoding imposes a stringent constraint on compression: the codeword bits used to recover a source symbol must reveal nothing about the remaining symbols beyond what the recovered symbol itself reveals. For memoryless sources, this constraint is known to be compatible with entropy-rate compression. We show that the same holds for any stationary ergodic source over a finite alphabet. Specifically, every rate above the entropy rate is achievable with exact privacy and error-free local decoding on a set of source sequences whose probability tends to one. In contrast, we exhibit non-ergodic sources for which private local decoding incurs a strictly positive rate penalty.
