# 用于发现和重用高阶网络数据集的存储库

- **arXiv**: [2608.03491](https://arxiv.org/abs/2608.03491)
- **日期**: 2026-08-04
- **分类**: network
- **作者**: Florian Frantzen, Michael T. Schaub
- **NOFX相关度**: 0

## 摘要

高阶网络数据集分散在出版物、机构档案和特定软件集合中，这使得它们难以发现、比较和重用。我们介绍了亚琛高阶网络存储库（AHORN），这是一个源自公开发布来源的标准化高阶网络数据集的精选存储库。每个数据集条目将转换后的数据集链接到其源、元数据、引文指南、转换代码和版本历史记录。该存储库支持可浏览和机器可读的发现、特定于修订版本的下载、格式验证和导出以实现互操作重用。我们描述了本文中分析的存储库架构、管理工作流程、访问工具以及目录快照的覆盖范围和局限性。
