# 帝国压力的拓扑特征：东地中海贸易网络的持久同源性，公元 0--400 年

- **arXiv**: [2605.27200](https://arxiv.org/abs/2605.27200)
- **日期**: 2026-05-26
- **分类**: network
- **作者**: Jose de Jesus Bernal Alvarado, David Delepine, Carlos Pinedo Guadarrama
- **NOFX相关度**: 0

## 摘要

我们将持久同源性应用于罗马世界的奥比斯地理空间网络模型，以量化公元 0 至 400 年间东地中海贸易网络的结构弹性。该网络被表示为一个加权运输系统，其边缘对应于公路、海上和河流路线，每条路线都有一个源自 ORBIS 成本模型的基本成本。为了将历史动态引入这种静态空间基础设施，我们构建了一个微分摩擦模型，其中边缘权重根据记录的历史扰动（包括流行病死亡率、内战、军事压力、行政重组和帝国统一）随十年和运输模式而变化。对于每个十年快照，我们计算活动子网络上的所有对最短路径距离，并使用由有限成对距离的第 90 个百分位定义的自适应阈值构建 Vietoris--Rips 过滤。由此产生的贝蒂数 ($β_1$) 持续熵时间序列确定了东地中海网络中三个结构不同的阶段。第一阶段，从公元 0 到 200 年，是一个固定的高冗余政权，与早期帝国和安东尼时期的商业一体化一致。第二阶段，从公元 210 年到 280 年，对应于第三世纪危机期间的可恢复应力：贝蒂数 ($β_1$) 熵在危机期间下降，但在奥勒利亚统一后回到第一阶段基线。第三阶段，从公元290年到400年，有质的不同：循环冗余度单调下降并且不会恢复。这项研究的主要贡献是表明，持久的同源性检测到帝国压力的一个维度，该维度不能简化为单一的经济、军事或政治指标。
