# 静态和动态网络上具有局部社会影响的集体决策的演化动力学

- **arXiv**: [2607.27233](https://arxiv.org/abs/2607.27233)
- **日期**: 2026-07-23
- **分类**: network
- **作者**: Yuyuan Liu, Xiaojie Chen
- **NOFX相关度**: 0

## 摘要

集体决策在生命世界和人工社会中无处不在。个人通常根据期权的内在价值来选择期权。然而，个人决策也会受到邻居选择的影响，产生当地的社会影响。因此，一个重要的问题自然而然地出现了，但仍未得到解答：当这种社会影响被纳入个人对选项选择的评估过程时，它如何影响以图为模型的结构化人群中的集体决策结果。为了解决这个问题，我们考虑具有社会影响力的二元期权基线模型，并假设个人不仅评估期权的内在价值，而且还受到邻居选择的影响。我们提出了一个将这两个方面结合起来的感知效用函数，用于个人决策。通过理论分析，我们首先得出静态加权连通图上选项的平均频率，并给出该选项在总体中占主导地位的数学条件。我们发现，社会影响力的引入可以放大优势选择的优势，或者弥补劣势选择的缺陷。我们还揭示了网络的平均程度对集体决策结果产生双重影响。此外，我们考虑了在不同图配置之间切换的动态网络的进化模型。我们的理论分析表明，进化结果不仅取决于每个网络配置的平均程度，还取决于其预期持续时间。我们进行计算机模拟来验证我们对静态和动态网络的理论预测。
