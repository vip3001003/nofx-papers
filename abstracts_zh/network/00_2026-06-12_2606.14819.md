# 噪声感知下的选择性控制：模块化网络中聚合指标隐藏的治理失败

- **arXiv**: [2606.14819](https://arxiv.org/abs/2606.14819)
- **日期**: 2026-06-12
- **分类**: network
- **作者**: Igor Itkin
- **NOFX相关度**: 0

## 摘要

内容审核系统可以在每个标准准确性指标上得分很高，但如果其错误落在连接其他独立社区的少数用户身上，仍然会造成真正的伤害。我们在基于代理的模型中展示了这一点，其中社区结构网络上的 N = 240 个学习代理每个都发布无害的、生产性的或危险的内容，并且监管者删除或惩罚嘈杂的分类器标记的任何内容。总体有用性几乎不会随着噪声的变化而变化（单向方差分析，p=0.96）：通过综合衡量，看起来没有什么问题。相反，损害集中在这些桥梁使用者身上，他们的有用岗位被错误地压制，而危险的岗位则被错误地幸免。在误报严重的噪音下，将这两个错误与执行成本分开定价的治理损失（L_gov）会增加一倍以上。聚合准确性隐藏了谁受到了伤害，而审计的廉价数量是用户拥有多少个连接（度），这是定义桥梁的介数的近乎完美的代理（r = 0.96）。
