# 用于帝国网络分析的双拓扑管道：持久同源性、结构脆弱性和阿兹特克崩溃

- **arXiv**: [2608.13845](https://arxiv.org/abs/2608.13845)
- **日期**: 2026-08-14
- **分类**: network
- **作者**: Jose de Jesus Bernal Alvarado, David Delepine, Carlos Pinedo Guadarrama
- **NOFX相关度**: 0

## 摘要

我们将持久同源性和双模型拓扑管道应用于阿兹特克帝国（三重联盟，公元 1427--1521 年）的多层网络，该网络根据贡品记录和 38 个节点（特诺奇蒂特兰中心、36 个贡税省份和特拉斯卡拉飞地）和 208 个边之间的地理邻接关系构建。我们报告了四个主要结果：（i）贡品（控制）层是一个纯粹的提取树（在所有时期$\bettione = 0$，$H = 0.000$）：结构上比使用相同管道分析的罗马、拜占庭或汉行政数据集中的任何记录配置更脆弱。 (ii) Tenochtitlan-Centro 的单节点去除将巨型组件从 1.000 折叠到 0.630，并同时消除 30 个冗余循环，相对于随机扰动的结构不对称比 $>4$:1。 (iii) 特拉斯卡拉-普埃布拉地区与帝国地理点云的主要 $\bettione$ 类重合（持久性 $= 22.09$~km，而所有其他点云的 $< 3$~km），无论特拉斯卡拉在过滤中建模为不存在还是存在，结构空隙都相同地存在。 (iv) 逻辑回归证实，地理层的商业中心性（$r = +0.462$，$p = 0.004$）是早期联盟形成的主要预测因素，而贡品负担则不相关（$r = -0.033$，$p = 0.845$）。这四个结果定义了一种新的帝国崩溃模式，即\emph{空占据树}，其中控制层中的零拓扑冗余与自治飞地占据的主要几何空位一致——历史网络TDA中之前未记录这种配置。
