# 在超大规模网络中实现量子通信

- **arXiv**: [2606.08326](https://arxiv.org/abs/2606.08326)
- **日期**: 2026-06-06
- **分类**: network
- **作者**: Filippo Radicchi
- **NOFX相关度**: 0

## 摘要

最近小规模量子网络的发展提出了这样的问题：这种技术是否也可以在未来的量子互联网中大规模运行。这个问题可以用经典方法来回答，其中任意量子网络被表示为经典图，并使用网络理论的适当方法来评估通信可靠性。不幸的是，仅针对规则晶格等特殊拓扑建立了可行的网络范围通信的充分条件。迄今为止，即使不是针对相对较小的网络，还没有针对实际网络拓扑开发出实用的通信协议。在这里，我们通过设计一系列量子通信协议克服了这些限制，这些协议可以应用于具有任意拓扑的网络，甚至由数亿个节点组成。通过对真实图和合成图进行系统分析，我们表明所提出的协议在异构网络上是可持续的。对于随机无标度图，我们分析证明可行的量子通信在热力学极限内持续存在。我们的研究结果证明，量子互联网将能够维持超大规模的增长，与其经典前身已经经历过的增长相当。
