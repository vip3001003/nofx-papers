# 沙堆模型重新布线对有向网络的影响

- **arXiv**: [2606.22092](https://arxiv.org/abs/2606.22092)
- **日期**: 2026-06-20
- **分类**: network
- **作者**: Alejandro Zamorano, Víctor Muñoz
- **NOFX相关度**: 0

## 摘要

一些研究考虑的不是规则网格上的沙堆动力学，而是网络上的沙堆动力学。在这种情况下，雪崩不是在几何意义上的相邻位置之间重新分配晶粒，而是在拓扑意义上的连接位置之间重新分配晶粒。然而，根据节点的连接方式，颗粒可能永远不会离开系统，从而阻止能量释放。在这项工作中，我们研究最简单的情况，一维和二维的 BTW 模型，重新布线节点，以便在每个重新布线步骤中，能量释放始终是可能的，并研究雪崩统计作为重新布线的函数。在 1D 情况下，在可能的重新布线数量约为 85% 时，观察到每个节点负载分布的基尼系数发生转变，这种转变在其他测量中并不明显，例如雪崩的大小分布或网络中节点之间的平均距离。在二维情况下，即使电网完全重新布线，能量释放也遵循幂律，而基尼系数与一维情况不同，以稳定的速率下降，过渡更加平滑。研究了网络大小 N 的影响，发现在一维和二维情况下，基尼系数在热力学极限 N 到 infty 处都有一个转变，这种转变也在介数中心性中观察到，但在其他拓扑度量中没有观察到。最后，研究了结果与每次重新布线迭代的负载以及雪崩阈值的相关性。
