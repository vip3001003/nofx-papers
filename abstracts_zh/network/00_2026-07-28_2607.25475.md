# 疾病死亡率和免疫力下降驱动的流行病动态和网络拓扑的协同演化

- **arXiv**: [2607.25475](https://arxiv.org/abs/2607.25475)
- **日期**: 2026-07-28
- **分类**: network
- **作者**: ThankGod I. S. Ikpe, Takayuki Hiraoka, Naoya Fujiwara
- **NOFX相关度**: 0

## 摘要

复杂网络上的流行病已被证明表现出受网络拓扑强烈影响的动态。然而，目前尚不清楚网络的拓扑结构如何受到流行病特性的影响，例如免疫力下降和疾病死亡率以及人口变化。为了探索流行病动态和网络拓扑之间的相互作用，我们开发了一种基于代理的致命传染病模型，该模型在最初无标度的网络上具有不完善的免疫力，该网络通过人口和流行病引起的变化而演变。我们表明，该模型经历了疾病最终消失阶段和流行阶段之间的流行病转变。此外，网络可能会因疫情蔓延而失去其无标度特性，从而导致拓扑从幂律分布向非幂律分布转变。我们使用基于代理的模型的异构平均场近似来验证我们的发现。这些结果凸显了在流行病模型中考虑网络演化的重要性，并增进了我们对协同演化动力系统的理解，其中疾病动力学和网络拓扑不断相互影响。
