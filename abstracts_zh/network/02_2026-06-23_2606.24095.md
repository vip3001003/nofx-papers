# 信任不确定性门控网络中的影响机制

- **arXiv**: [2606.24095](https://arxiv.org/abs/2606.24095)
- **日期**: 2026-06-23
- **分类**: network
- **作者**: Razieh Masoumi, Ahana Biswas, Yu-Ru Lin
- **NOFX相关度**: 2

## 摘要

在许多社会社区中，个人可以同时信任和不信任同一来源，这是标准意见动态模型经常忽略的一个特征。我们用门控网络信任来形式化这种矛盾心理，其中每个有向关系都编码不同的信任和不信任评估。这些共同决定了“净信任”（愿意依赖某个来源）和“不确定性”（同一关系中信任与不信任之间的冲突）。仅当网络信任超过阈值并且不确定性低于另一个阈值时，代理才会更新信念，从而产生有效的影响图，其拓扑驱动长期信念状态。扫过这两个门槛就会发现四种政权——多元化、选择性、协调性和强化——它们对信任和冲突的开放程度有所不同。我们发现了一致的中心-外围逆转：在选择性政权中，高级别代理人主导影响力，而在一致政权中，严格的不确定性过滤不成比例地消除了与高级别代理人相关的主动影响渠道，使外围较低级别的代理人能够对集体均衡发挥更大的影响力。这种逆转在综合网络和经验网络中都成立。我们的结果表明，信念动态不仅取决于网络结构，还取决于信任和不信任之间的关系矛盾如何影响人际影响。
