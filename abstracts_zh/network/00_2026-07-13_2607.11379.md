# 用于图压缩的双曲嵌入

- **arXiv**: [2607.11379](https://arxiv.org/abs/2607.11379)
- **日期**: 2026-07-13
- **分类**: network
- **作者**: Dorota Celinska-Kopczynska, Eryk Kopczynski
- **NOFX相关度**: 0

## 摘要

网络理论家假设现实世界网络的结构具有几何起源。特别是，双曲几何在无标度网络的表示和建模方面被证明具有深刻的洞察力。嵌入器是用于查找网络几何表示的算法。在本研究中，我们介绍了一种基于现代双曲嵌入器的快速无损图压缩算法。对现实世界和生成网络的实验验证表明，我们的算法在现实世界的图表上比最先进的算法高出 42%。
