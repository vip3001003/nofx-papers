# 量化基于事件的时态网络和超图数据中的并发性

- **arXiv**: [2605.24633](https://arxiv.org/abs/2605.24633)
- **日期**: 2026-05-23
- **分类**: network
- **作者**: Jiyoung Kang, Hang-Hyun Jo, Naoki Masuda
- **NOFX相关度**: 0

## 摘要

许多社会、生物和技术系统都被记录为带有时间戳的交互序列。在这样的系统中，并发性，即个体几乎同时参与多种交互的倾向，可以强烈影响流行病或信息传播等过程。然而，基于事件的时态网络数据的并发措施尚未建立。我们引入了边缘事件相关性（EEC），这是一种简单且可解释的测量方法，可以量化两个连接随时间的活跃程度的相似程度。我们将 EEC 应用于经验时间网络和时间超图，后者允许单个事件涉及两个以上的节点。在大多数数据集中，共享节点的边对或超边比不共享节点的边对或超边显示出更高的并发性。我们进一步发现，这种并发性的提高主要是由嵌入封闭局部结构中的对驱动的，例如聚合网络中的三角形。 EEC 提供了一种实用工具，用于量化基于事件的时态数据中的并发性，并可能有助于识别促进快速传播或集体动态的网络结构。
