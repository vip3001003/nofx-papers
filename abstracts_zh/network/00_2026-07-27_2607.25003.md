# 城域网络中的系统最优性与自组织：最优传输分析

- **arXiv**: [2607.25003](https://arxiv.org/abs/2607.25003)
- **日期**: 2026-07-27
- **分类**: network
- **作者**: Tianyu Dong, Jiazu Zhou, Markus Schläpfer
- **NOFX相关度**: 0

## 摘要

城市交通网络设计通常通过以工程和经济学为基础的自上而下的规划来进行。然而，城市是一个复杂的系统，其特点是基础设施和出行需求之间存在反馈循环：网络结构决定出发地-目的地 (OD) 流量，而 OD 流量会适应并反过来影响网络发展。尽管存在这种相互依赖性，但根据替代生成原理对现实世界网络进行基准测试的计算工具仍然有限。在这里，我们引入一个数据驱动的框架来比较三种类型的地铁网络：源自局部规则的自组织（期望路径）网络、源自全局优化的系统最优网络以及经验现实世界网络。我们使用几何比较和最优传输理论来量化相似性和差异。将该框架应用于新加坡的大众捷运系统，我们发现经验地铁网络比系统最优基准更接近自组织基准，其余差异很大程度上是由地理限制造成的。这些发现强调，仅靠全系统最优性可能不足以指导实际干预措施、激励明确纳入当地服务需求的规划方法。该框架可跨地区转移，并可以诊断设计与使用的不一致，以支持适应性基础设施规划。
