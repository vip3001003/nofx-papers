# 本地网络增长：简单规则如何导致网络复杂性

- **arXiv**: [2608.01853](https://arxiv.org/abs/2608.01853)
- **日期**: 2026-08-03
- **分类**: network
- **作者**: Alexei Vazquez
- **NOFX相关度**: 0

## 摘要

互联网、一个活细胞、一个朋友圈、一个耗资十亿美元的建设项目：这些系统几乎没有任何共享——然而，当绘制成网络时，它们看起来惊人地相似。每一个都在众多稀疏连接的节点中拥有几个巨大的枢纽，任意两个部分之间的短路径，密集的本地集群、社区和许多冗余路线。二十年来，这种模式一直被认为是“优先依恋”，即富者愈富——从字面上看，这一规则要求每个新来者在连接之前对整个网络进行调查。本书提出了一个更简单的案例，并一次为一种机制辩护：真实网络的全局规律不是从上面强加的，而是从纯粹的局部规则中产生的，其中每个新节点仅作用于它所到达的节点以及该节点的直接邻居。浏览链接的冲浪者、朋友介绍朋友、复制其连接的基因——没有人将网络作为一个整体进行咨询，但每个人都在总体上构建了一个真实复杂系统的完整且明确无误的签名。它是为好奇的读者和专家而写的，用简单的语言讲述了想法，并将数学放在可以跳过的盒子里，它展示了引文图、网络、社会关系、蛋白质相互作用和项目进度表如何从同一批本地规则中成长起来——一次一个本地决策。
