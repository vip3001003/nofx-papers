# 时间网络上的传播结构

- **arXiv**: [2608.06175](https://arxiv.org/abs/2608.06175)
- **日期**: 2026-08-06
- **分类**: network
- **作者**: Omar Henderson, Mikko Kivelä, Márton Karsai
- **NOFX相关度**: 0

## 摘要

通过映射到渗透，可以很好地理解静态网络中传播的物理原理。我们表明，时间网络上的传播动态可以类似地映射到时间事件图中的可达性。这为一类过程提供了理论和计算框架，例如易感者-感染者-易感模型的变体。在没有显式模拟的情况下，通过事件图的成分分析，我们获得流行病流行率并推导具有任意程度和事件间时间分布的时间网络的流行病阈值，与显式模拟相比具有显着的计算优势。
