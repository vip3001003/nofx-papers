# 有向网络的巨型强双连通分量：生成函数方法

- **arXiv**: [2608.25562](https://arxiv.org/abs/2608.25562)
- **日期**: 2026-08-26
- **分类**: network
- **作者**: Minsoo Yang, Reinhard Laubenbacher, Byungjoon Min
- **NOFX相关度**: 0

## 摘要

强连接组件（SCC）是有向网络中模块化结构的特征，但对单节点故障很脆弱。我们研究强双连接组件（SBC），这是一组节点，其中每个节点对在删除任何单个节点后仍然相互可达，作为更稳健的连接概念。使用生成函数形式，我们推导了巨型 SBC 的大小，并分析了其在随机节点和链接删除下的渗透行为。我们发现，巨型 SBC 的出现与巨型 SCC 的门槛相同，但由于更严格的连接要求，其增长速度更为缓慢。我们还将我们的理论框架应用于现实世界的生物网络，包括基因调控网络和神经连接组。我们的框架提供了对复杂定向系统中连接性、冗余性和鲁棒性之间相互作用的洞察。
