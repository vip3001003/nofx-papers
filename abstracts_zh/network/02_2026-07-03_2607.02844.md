# 具有部分功能的多路流网络中基于过载的级联

- **arXiv**: [2607.02844](https://arxiv.org/abs/2607.02844)
- **日期**: 2026-07-03
- **分类**: network
- **作者**: Orkun İrsoy, Osman Yağan
- **NOFX相关度**: 2

## 摘要

由负载或流量重新分配驱动的级联故障出现在电网、供应链和云计算中心等网络系统中。大多数流网络模型都假设节点作为一个整体起作用或失效。然而，在许多实际系统中，一个节点支持多个共享节点级资源的不同流，其中一个流发生故障并不一定意味着其他流也发生故障。我们通过具有部分功能的多路复用流网络来研究这种设置，其中节点可以在某些功能中保持运行，而在其他功能中出现故障。一项功能的重负载会降低其他功能的可用容量，这可以通过跨层影响因素来量化。当某一层中的节点发生故障时，其负载将在该层中的幸存节点之间重新分配，而该节点可以在其他层中继续运行。使用平均场分析，我们推导出最终系统大小的递归方程，即级联停止后每层中幸存节点的比例。我们通过对几种负载能力分布的模拟来验证分析。然后，我们研究级联动力学的关键特征，包括非单调鲁棒性曲线、不同的级联结果机制及其与跨层影响的关系。我们将结果映射到不同的稳态状态，包括联合功能模型中缺少的单层生存阶段，并表明部分功能可以提高相对于联合功能情况的鲁棒性。最后，我们通过比较几种容量分配策略来研究固定总容量预算下的鲁棒性最大化。我们提出了一种策略，将跨层影响与负载和程度的局部邻域信息相结合，并表明它在所考虑的配置中提供了最强的鲁棒性性能。
