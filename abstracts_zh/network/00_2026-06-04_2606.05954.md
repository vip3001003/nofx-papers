# 网络模型选择：方法回顾

- **arXiv**: [2606.05954](https://arxiv.org/abs/2606.05954)
- **日期**: 2026-06-04
- **分类**: network
- **作者**: Zoran Levnajić
- **NOFX相关度**: 0

## 摘要

了解复杂网络演化背后的过程是网络科学的一个关键目标。应对这一挑战的有效框架是网络模型选择，其中包括从一组候选模型中找到最能解释给定网络的模型。本书是对用于此目的的方法的系统回顾。每种方法都分为三个部分：其核心原理（用于将方法分为四类）、其他相关细节（包括我自己的观察）和软件可用性。本书全面概述了网络模型选择的最新技术，并通过探索未来的方向进行了总结。统一的最佳方法可以比任何现有方法更精确地识别塑造现实世界网络的机制。这项工作代表了开发这种最佳方法的第一步。对于网络科学领域的学生和研究人员来说，这将是宝贵的资源。
