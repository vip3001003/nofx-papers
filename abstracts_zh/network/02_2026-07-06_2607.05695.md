# 罗马-拜占庭贸易网络的结构分歧，0--1453\，CE：持久同源性、拓扑速度和帝国崩溃的临界指标

- **arXiv**: [2607.05695](https://arxiv.org/abs/2607.05695)
- **日期**: 2026-07-06
- **分类**: network
- **作者**: Jose de Jesus Bernal-Alvarado, David Delepine, Carlos Pinedo Guadarrama
- **NOFX相关度**: 2

## 摘要

我们使用针对 \textsc{orbis} 地理空间网络模型校准的 2{,}599 个节点和 4{,}503 个三峰边，将 ~\paperone{} 的持久同源分析扩展到完整的罗马-拜占庭贸易网络 (0--1453\,\textsc{ce})。报告了五个结果。 % (i)~~\paperone{} 的 $H_t{=}0$ 西部子网络结果是一个数据覆盖工件：具有完整的西部表示（$N_{\rm west}=987$，每十年 $β_1\approx52$ 周期），$+2.22$ 单位的基线东西向熵差距从 0\,\textsc{ce} 开始出现，并在$+3.3\times10^{-3}$\,yr$^{-1}$，早于狄奥多西分裂四个世纪。 % (ii)~度异质网络中的\emph{集线器选择伪影}可以反转推断的第三阶段斜率的符号，需要全覆盖或分层采样以进行可靠的结构断裂检测。 % (iii)~将拜占庭复原力分解为地理 ($H_{\rm geo}$) 和经济 ($H_{\rm eco}$) 部分，揭示了在 620\,\textsc{ce} 时峰值脱钩比率 $R_d = H_{\rm eco}/H_{\rm geo} = 47.7$，在 640\,\textsc{ce} 时降至 13.9，量化了麦考密克-沃德-帕金斯的史学争论是在不同时间尺度上运行的两个网络层之间的对比。 % (iv)~十年间 $W_2$ Wasserstein 速度将罗马晚期-拜占庭早期过渡 (495\,\textsc{ce}) 确定为 1,453 年记录中最高的拓扑速度事件；在 Chrysobull 1082\,\textsc{ce} 之后，跨网络 Wasserstein 比率增加了 $150$--$300\times$，提供了 $R_d$ 的独立图空间模拟。西方崩溃 (476\,\textsc{ce}) 和拜占庭端点 (1453\,\textsc{ce}) 都发生在 $H^{\ast}\approx0.524$，被解释为候选拓扑渗流阈值。
