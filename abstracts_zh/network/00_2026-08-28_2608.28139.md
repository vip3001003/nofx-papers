# 中国本土偏见的缩小和破坏性影响的上升：来自全球引文网络分析的证据

- **arXiv**: [2608.28139](https://arxiv.org/abs/2608.28139)
- **日期**: 2026-08-28
- **分类**: network
- **作者**: Nan Deng, Zheng Ma, Xiaohui Liu
- **NOFX相关度**: 0

## 摘要

中国已成为世界上最大的科学出版物生产国，但人们仍然担心国内过度的引用行为会夸大这种增长。在这项研究中，我们分析了 Web of Science（1980-2025 年）超过 4500 万篇出版物的引用网络，以调查中国的本土引用偏差和研究影响。使用网络重组零模型来控制出版物量的结构效应，我们发现中国的本土引用偏差没有通常假设的那么明显，并且在过去二十年中一直在稳步下降。与其他主要国家相比，中国研究人员并没有表现出明显更强的国内引用偏好，这表明国际化程度不断提高，而不是孤立性。此外，利用持续颠覆框架，我们表明中国论文在产生范式转变工作的能力方面正在向美国论文靠拢。这些发现挑战了有关中国科学本土偏见的普遍说法，并表明中国在研究方面的进步产生了影响。
