# 通过控制时间交互网络来控制动态

- **arXiv**: [2607.04998](https://arxiv.org/abs/2607.04998)
- **日期**: 2026-07-06
- **分类**: network
- **作者**: Melvyn Tyloo
- **NOFX相关度**: 0

## 摘要

许多现实世界的耦合动力系统具有随时间演变或适应的相互作用结构和强度。在这里，我们研究如何通过调整时间交互网络来控制系统的状态。我们提出了一种基于非线性最优控制的框架，其中可以控制动态系统的耦合矩阵。我们展示了如何使用伴随方法获得系统拉格朗日函数的梯度。然后，我们重点关注线性时变系统，并对其框架进行说明。最后，我们探索如何通过控制耦合矩阵，对其结构施加各种约束，将节点处的状态引导至目标轨迹。此处介绍的工作流程可用于通过可调节的人工或工程交互来引导系统的动态。
