# 谣言在社区网络中传播

- **arXiv**: [2607.08546](https://arxiv.org/abs/2607.08546)
- **日期**: 2026-07-09
- **分类**: network
- **作者**: Zhaoxi Cui, Anthony O'Hare
- **NOFX相关度**: 0

## 摘要

许多现实世界的网络具有这样的特征，即它们由不同的群体或社区组成，其成员在社区内包含许多链接，但与其他人的联系较少。准确地对这些类型的网络进行建模以正确预测疾病传播或信息流等重要传播过程的结果非常重要。我们的激励示例是对冲基金等多个投资机构内的交易者网络。我们假设一个理想化的场景，即同一机构内的交易者有很多联系人，可以快速、轻松地共享信息，但与其他机构的交易者的联系较少，依赖于个人网络，从而允许信息在社区内轻松流动，而在社区之间则不那么容易。在本文中，我们研究了一个特定的传播过程，即谣言在基于社区的网络上的传播，该网络具有两个参数：组内连通性和组间连通性。我们表明，此类网络与通常用于对系统类型进行建模的小世界或随机网络具有不同的特征，并且网络拓扑对网络上谣言的传播具有很小但并非微不足道的影响。
