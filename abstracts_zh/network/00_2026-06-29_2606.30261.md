# 网络中强大的秘密存储

- **arXiv**: [2606.30261](https://arxiv.org/abs/2606.30261)
- **日期**: 2026-06-29
- **分类**: network
- **作者**: Vinko Zlatić
- **NOFX相关度**: 0

## 摘要

研究了在网络上存储安全信息的问题。介绍了分布式秘密存储的正式框架，并讨论了在技术和社会系统中的可能应用。该问题被表述为鲁棒性函数的优化，其中平衡了两个相互竞争的要求：网络退化过程下的生存性和对抗性妥协的抵抗力。生存性的精确表示是根据最小信息携带子图（MICS）得出的，它提供了与存储信息相关的重建事件的简化描述。然后使用该表示来构建半局部优化方法，其动力学不需要网络结构的全局知识。最后，结果表明，在极限情况下，鲁棒性函数可以自然地映射到有效的自旋哈密顿量。
