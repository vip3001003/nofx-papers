# Hypergraphx-data：高阶网络数据的存储库

- **arXiv**: [2605.18166](https://arxiv.org/abs/2605.18166)
- **日期**: 2026-05-18
- **分类**: network
- **作者**: Quintino Francesco Lotito, Lorenzo Betti, Berné Nortier et al.
- **NOFX相关度**: 0

## 摘要

网络数据集的可用性通过实现实证分析及其再现性、算法开发、模型验证和基准测试来推进网络科学、机器学习和相关领域的研究。现有的存储库（例如 SNAP 和 Netzschleuder）已经通过元数据、指标和基本可视化使传统网络数据集可以广泛访问。然而，它们主要关注成对交互，限制了对多体交互系统的数据访问。为了解决这一差距，我们创建了 hypergraphx-data，这是一个用于高阶网络分析的现实世界超图数据集存储库，涵盖从社交网络到生物学和金融的不同领域，并支持加权、有向、时间和多重超图等配置。每个数据集都包含关系信息和元数据，以开放 JSON 格式和 Hypergraphx 的二进制格式提供。我们提供了一个用户友好的界面，以方便浏览、过滤和访问数据集，同时还通过基于哈希的验证和数据版本控制来确保完整性和可重复性。该存储库位于 https://hgx-team.github.io/hypergraphx-data
