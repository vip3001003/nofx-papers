# 宏观强化调整可逆社会传染的过渡顺序

- **arXiv**: [2607.04354](https://arxiv.org/abs/2607.04354)
- **日期**: 2026-07-05
- **分类**: network
- **作者**: Guanyu Zhang, Peng-Bi Cui
- **NOFX相关度**: 3

## 摘要

社会传染往往是通过强化形成的：随着接触的积累或采用变得广泛可见，个人更有可能采用新的行为、观点或产品。现有的网络模型主要通过局部机制来捕获这种效应，例如阈值响应或高阶交互。然而，宏观层面的强化如何重塑可逆扩散仍不清楚。在这里，我们研究了一个类似 SIS 的过程，其中成对传播因全球流行率而得到加强。结合准稳态模拟和分岔分析，我们表明全局反馈可以产生一阶转变和磁滞回线，具有不同的激活和崩溃阈值。我们进一步展示了网络本地化如何促进局部点火，同时削弱突然宏观激活所需的全局流行信号，从而提高强化阈值。我们的结果揭示了与网络结构耦合的全局反馈如何出现起始-撤退不对称性，为突然的、依赖于历史的可逆社会传染提供了最小的机制。
