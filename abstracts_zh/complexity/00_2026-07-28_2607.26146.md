# 具有非完整约束的机械系统的 Lindbladian 量化

- **arXiv**: [2607.26146](https://arxiv.org/abs/2607.26146)
- **日期**: 2026-07-28
- **分类**: complexity
- **作者**: Daniel Schubring, Sriram Ganeshan
- **NOFX相关度**: 0

## 摘要

非完整力学描述了受不可积速度约束的系统，例如滚动体和滑行运动。这些系统通常缺乏规范的哈密顿公式，阻碍了标准的量化方法。在这里，我们将非完整系统量化为马尔可夫开放量子系统，非完整约束出现在大耗散极限中。我们发现了明确的 Lindblad 超级算子，可以在半经典极限下再现 Chaplygin 雪橇的经典动力学和 Suslov 问题。对主方程进行了数值模拟，并且证明协方差满足开放量子系统中亚稳态理论所预测的关系。
