# Relaxation Critical Dynamics of Strong-to-Weak Spontaneous Symmetry Breaking

- **arXiv**: [2611.20581](https://arxiv.org/abs/2611.20581)
- **日期**: 2026-11-16
- **分类**: complexity
- **作者**: Jiaqiang Li, Xianquan Yan, Han-Ze Li et al.
- **NOFX相关度**: 4

## 摘要

Strong-to-weak spontaneous symmetry breaking (SW-SSB) is unique to mixed states: strong symmetry is broken while weak symmetry is preserved, requiring two order parameters. We study the critical relaxation of both order parameters in a monitored $\mathbb{Z}_2$ circuit, which maps exactly onto two nested bond-percolation problems. The initial state acts as a temporal boundary condition for each problem, wired if the state is ordered in the corresponding order parameter and free otherwise. An SW-SSB initial state wires only the strong-symmetry order parameter, a configuration that no pure state realizes. Each autocorrelation exponent is the sum of an initial scaling dimension, set by the initial state, and an observation dimension, set by the observation time, whereas the equal-time correlator gives only the observation dimension. For the SW-SSB state, the initial dimension is $1/3$ for the weak-symmetry order parameter and $0$ for the strong-symmetry one, each at its own critical point. These initial dimensions also set how fast a stored bit is lost. The probability of decoding the initial value of a single qubit from the system alone decays as a power law, whereas system and environment together retain it. Stabilizer simulations confirm the theoretical prediction, and we propose an experimental protocol that measures these exponents without postselection. Our results reveal a form of boundary criticality inaccessible to pure states.
