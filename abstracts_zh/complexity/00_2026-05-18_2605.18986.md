# 随机量子态的非高斯性

- **arXiv**: [2605.18986](https://arxiv.org/abs/2605.18986)
- **日期**: 2026-05-18
- **分类**: complexity
- **作者**: Filiberto Ares, Sara Murciano, Pasquale Calabrese
- **NOFX相关度**: 0

## 摘要

我们研究典型量子态中的费米子非高斯性，重点关注具有或不具有全局 $U(1)$ 对称性的量子位的哈尔随机态。使用温加滕演算，我们得出非高斯性的分析预测，定义为约化密度矩阵与其高斯化对应矩阵之间的相对熵。我们确定了由子系统和系统规模之间的比率 $\ell/L$ 控制的两种机制。对于 $\ell/L < 1/2$，在不存在对称性的情况下非高斯性消失，因为典型的约简密度矩阵以指数方式接近最大混合状态。相反，在存在全局 $U(1)$ 对称性的情况下，它仍然很小但有限。相比之下，在 $\ell/L > 1/2$ 的情况下，非高斯性变得广泛。这些结果建立了随机状态下费米子非高斯性的典型标度，并分析了全局对称性的存在如何对其进行修改。
