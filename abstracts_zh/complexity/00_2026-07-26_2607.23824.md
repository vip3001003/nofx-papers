# 二维 Uhlenbeck-Ford 模型：流体相自由能计算的参考系统

- **arXiv**: [2607.23824](https://arxiv.org/abs/2607.23824)
- **日期**: 2026-07-26
- **分类**: complexity
- **作者**: Samuel Cajahuaringa, Rodolfo Paula Leite, Maurice de Koning
- **NOFX相关度**: 0

## 摘要

我们研究 Uhlenbeck-Ford (UF) 模型作为二维 (2D) 流体自由能计算的参考系统。二维维里系数精确计算到十阶，并与分子模拟数据相结合，构建状态方程和过量亥姆霍兹自由能的高精度数值表示。然后，我们确定模型的相图，以建立流体相的热力学稳定极限，从而确定 UF 模型作为流体参考系统的适用范围。在此分析过程中，我们识别了固相、六方相和流体相，并表明流体仍然是唯一的热力学稳定相，与密度无关，缩放参数高达 $p\lesssim 70$。最后，我们通过二维 Lennard-Jones 流体自由能的热力学积分计算证明了 2D UF 模型作为参考系统的实际适用性。
