# 量子纠错中的子系统对称性和分形模型

- **arXiv**: [2608.18961](https://arxiv.org/abs/2608.18961)
- **日期**: 2026-08-19
- **分类**: complexity
- **作者**: Giovanni Canossa
- **NOFX相关度**: 0

## 摘要

构建新的量子代码并了解其容错能力是开发鲁棒量子存储器的核心挑战。拓扑码因其良好的纠错特性以及与多体物理学中物质相的联系而特别有前途。在本论文中，我们通过子系统对称性、分​​形拓扑序和 Kramers-Wannier 型对偶性探索经典伊辛模型和量子纠错之间的相互作用。我们研究了两个具有子系统对称性的三维经典自对偶 Ising 模型，即四面体 Ising 模型和分形 Ising 模型，通过子系统对称性测量研究了它们的热行为、它们与分形相的关系以及所得分形代码的属性。使用统计机械映射，我们确定棋盘码的最佳代码容量阈值为$0.107(3)$，这饱和了CSS代码的理论极限，并且代表了已知三维码中最高的最佳错误阈值。我们将这种饱和度与满足 Kramers-Wannier 型对偶性的经典自旋模型的广义熵关系联系起来，并讨论这种预测如何扩展到零编码率的 CSS 代码，其 $X$- 和 $Z$- 噪声模型映射到经典的双自旋模型。这些发现将分形码确立为量子存储器的高弹性候选者，并证明了统计力学框架及其对偶预测在分析和构建鲁棒量子纠错码方面的力量。
