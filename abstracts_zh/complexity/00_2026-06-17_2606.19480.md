# sft-wick：随机场论中费曼图扩展和评估的形式主义和包

- **arXiv**: [2606.19480](https://arxiv.org/abs/2606.19480)
- **日期**: 2026-06-17
- **分类**: complexity
- **作者**: Zheng Zhang
- **NOFX相关度**: 0

## 摘要

当随机场动力学被转化为路径积分公式时，微扰理论变得系统化，但由此产生的扩展很快变得组合大。这里的目标设置包括具有矩阵传播器的多分量、多维场、张量值耦合以及由任意 $n$ 点累积量指定的非高斯驱动噪声。灯芯配对按阶乘增长，并且分量索引必须通过张量值顶点进行路由。有用的输出不是原始收缩列表，而是图表：每个拓扑一个条目，并解决了多重性、耦合和、符号和因果约束。我们提出了 sft-wick，一个开源 Python 包，它可以构建这些图表并以数值方式计算它们的积分。给定一个动作和一个可观察量，它枚举拓扑上不同的费曼图，导出它们的代数系数，并根据用户提供的响应和累积函数评估结果图积分。核心算法在路由组件索引之前枚举空间拓扑，避免逐个收缩的 Wick 扩展。在计数过程中强制执行响应场约束，包括消失的响应-响应收缩、伊藤处方和因果响应循环的缺失。预测根据直接 Langevin 模拟进行验证，与模拟的统计噪声一致。
