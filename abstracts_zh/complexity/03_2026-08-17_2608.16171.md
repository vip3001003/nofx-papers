# Rare-event sampling for stochastic dynamics in network systems using cluster updates

- **arXiv**: [2608.16171](https://arxiv.org/abs/2608.16171)
- **日期**: 2026-08-17
- **分类**: complexity
- **作者**: Jiazheng Sun, James Moody, Thomas Barthel
- **NOFX相关度**: 3

## 摘要

理解复杂网络中的随机演化是物理学、生物学、工程学、社会科学和金融领域的一个核心挑战。最重要的宏观事件，例如通讯网络的级联故障、广泛的流行病爆发以及社会舆论的快速转变，往往是由罕见的局部随机过程汇合而成，需要克服某些瓶颈。由于灾难性的拒绝率，像 Gillespie 方法这样的标准正向时间模拟算法对于研究此类现象效率低下。先进的罕见事件技术，如分裂方法和转移路径采样，在应用于复杂的异构网络时，通常会遇到动力学捕获、路径简并、谱系相关性或严重减速的问题。我们建议通过建立一种称为条件路径蒙特卡罗（CPMC）的新技术来克服这一挑战，该技术受到平衡凝聚态物理循环算法的启发。通过在时空簇上采用非局部更新而不排斥，CPMC 生成了一条马尔可夫轨迹链，所有轨迹都严格遵守目标宏观边界条件，例如发生大规模网络故障。我们通过对亲属网络上 SIS 动态中罕见的大规模流行病爆发进行简单的风险因素分析，展示了该框架的潜力。
