# 俘获量子 Calogero 模型中的精确相空间旋转

- **arXiv**: [2609.08987](https://arxiv.org/abs/2609.08987)
- **日期**: 2026-09-08
- **分类**: complexity
- **作者**: Akash Sarkar
- **NOFX相关度**: 0

## 摘要

我们在存在外部谐波限制势的情况下开发了量子卡洛杰罗模型的微观相空间描述。基于量子 Lax 对结构，我们构造了一个 Hermitian Wigner 算子，对于任意初始状态和相互作用强度的所有阶，其期望值服从精确的相空间演化方程 d_t rho + lambda d_x rho - Omega^2 x d_lambda rho = 0。由此产生的动力学是周期为 2 pi/Omega 的相空间中的刚性旋转，提供了捕获的 Calogero 模型的等时动力学的微观实现。我们进一步表明，相空间密度的矩形成旋转多重态，而不是独立的守恒量。特别是，在二次扇区内，独特的保守组合与捕获的哈密顿量成正比，从而提供了构造的非平凡一致性检查。在极限 Omega -> 0 下，方程简化为未捕获模型的精确自由流方程。
