# When the Boundary Changes the Bulk: Topological Edge Modes in Dynamical Quantum Phase Transitions

- **arXiv**: [2611.19328](https://arxiv.org/abs/2611.19328)
- **日期**: 2026-11-14
- **分类**: complexity
- **作者**: N. Sedlmayr, J. Sirker
- **NOFX相关度**: 2

## 摘要

For dynamical quantum phase transitions (DQPTs) in open chains it has been noted that the boundary can change the bulk: in time windows bounded by DQPTs, exponentially localized edge modes of the Loschmidt matrix produce a finite change in the intensive return rate. These modes have been attributed to topological properties of the initial and final Hamiltonians. Here we show that it is not the topology of the Hamiltonians but rather that of the non-Hermitian Loschmidt matrix which protects these edge modes. In particular, we show that topological edge modes can exist in class A, where both Hamiltonians are topologically trivial. For classes A, BDI, and AIII we show that these modes are protected by $\mathbb{Z}$ indices of a Toeplitz operator and that K-splitting theorems provide a precise bulk-boundary correspondence. In class D, they are protected instead by a $\mathbb{Z}_2$ index that records whether the quench has flipped the fermion parity at the edge. The bulk invariant for class D can be formulated either as a ratio of the Loschmidt amplitudes for periodic and anti-periodic boundary conditions or as a winding number that counts phase vortices in momentum and time. We discuss examples and provide numerical data for all four topological classes.
