# Reliable arithmetic circuits using less reliable (sub-digital) logic

- **arXiv**: [2611.24591](https://arxiv.org/abs/2611.24591)
- **日期**: 2026-11-18
- **分类**: complexity
- **作者**: Trevor McCourt, Ila R. Fiete, Neil Gershenfeld et al.
- **NOFX相关度**: 0

## 摘要

The frequent static failure of CMOS logic gates at ultra-low voltages has historically been perceived as a strict barrier to extreme voltage scaling: this paper introduces a statistical circuit law proving this intuition wrong. We discovered a universal power law connecting gate and circuit static failure probabilities, revealing that circuit failure requires the simultaneous breakdown of an entire gate cluster rather than a single component. Because the required cluster size increases rapidly as voltage drops, low-voltage \textit{sub-digital} logic exhibits surprising inherent resilience to static failure. This insight stems from new theoretical tools we developed to quantify static failure, extending well beyond conventional voltage-margin analysis. Consequently, sub-digital processors could potentially offer a viable, near-term solution to drastically reduce the energy demands of AI.
