# 超越解释的方差：PCA 的警示故事

- **arXiv**: [2605.13520](https://arxiv.org/abs/2605.13520)
- **日期**: 2026-05-13
- **分类**: complexity
- **作者**: Gionni Marchetti
- **NOFX相关度**: 0

## 摘要

我们解决了主成分分析 (PCA) 的缺点，用于通过二维散点图可视化位于非线性低维流形上的高维数据，重点关注早期哺乳动物食虫动物 Kuehneotherium 的化石牙齿数据集。虽然 Jolliffe 和 Cadima 报告的 PCA 散点图（Philosophical Transactions of the Royal Society A，2016）显示在 PC2 < 0 的区域中存在聚类，但我们基于 t-SNE 和持久同源性 (PH) 的分析揭示了一种环状结构，没有明显的聚类且内在维数等于 1。我们进一步提出了一种生成概率几何模型，其中数据从单位圆均匀采样。在该模型下，成对余弦距离遵循反正弦分布，与观察到的 U 形分布定性一致，从而独立支持基于 tt t-SNE 和持久同源性的分析。
