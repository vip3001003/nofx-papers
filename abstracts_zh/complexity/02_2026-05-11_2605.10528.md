# LLM多智能体系统中的集体协调：通过统计物理消除合作中的偏见

- **arXiv**: [2605.10528](https://arxiv.org/abs/2605.10528)
- **日期**: 2026-05-11
- **分类**: complexity
- **作者**: Cristiano De Nobili
- **NOFX相关度**: 2

## 摘要

我们研究了二维方格上基于 LLM 的多智能体系统的新兴集体动力学，并提出了一种与模型无关的统计物理方法，以将社会一致性与内在偏见分开，计算关键指数，并探讨多智能体系统的集体行为和可能的相变。在我们的框架中，$L\!\times\!L$ 网格的每个节点都托管一个相同的 LLM 代理，该代理持有二进制状态（$+1$/$-1$，映射到是/否），并通过查询以四个最近邻状态为条件的模型来更新它。采样器温度 $T$ 作为唯一的控制参数。在三个开放权重模型（llama3.1:8b、phi4-mini:3.8b、mistral:7b）中，我们在旨在探测 $\mathbb{Z}_2$ 对称性的全局翻转协议下测量磁化强度和磁化率。所有模型均显示温度驱动的有序-无序交叉和磁化率峰值；偶数 $L$ 晶格上的有限尺寸缩放会产生有效指数 $γ/ν$，其值与模型相关，接近但不兼容 2D Ising 普适性类 ($γ/ν=7/4$)。我们的方法能够提取有效的$β$加权耦合$\tilde{J}(T)$和字段$\tilde{h}(T)$，作为社会一致性和内在偏见的衡量标准。在我们分析的模型中，我们发现集体对齐由内在偏差 ($\tilde{h}\gg\tilde{J}$) 主导，而不是由合作邻居耦合主导，从而产生场驱动的交叉而不是真正的相变。这些有效参数在不同模型中存在质的差异，为 LLM 智能体提供紧凑的集体行为指纹，并为多智能体共识和集体一致性的可靠性提供定量诊断。
