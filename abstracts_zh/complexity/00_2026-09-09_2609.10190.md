# pyeCE：嵌入式集群扩展的 Python 实现

- **arXiv**: [2609.10190](https://arxiv.org/abs/2609.10190)
- **日期**: 2026-09-09
- **分类**: complexity
- **作者**: Yann L. Müller, Claire A. Paetsch, Anirudh Raju Natarajan
- **NOFX相关度**: 0

## 摘要

簇展开是一种广泛使用的方法，用于通过零开尔文第一原理计算来预测合金的有限温度热力学，但其传统公式对于具有超过三种或四种化学物质的材料变得棘手。因此，高熵合金在很大程度上仍然遥不可及。我们提出了 pyeCE，一个开源 Python 库，它实现了嵌入式簇扩展 (eCE)，其中机器学习将许多化学物质映射到较小的有效物质集合，从而限制簇函数数量的增长。 pyeCE 提供完整的建模工作流程，包括使用可学习的每子晶格化学嵌入构建对称性自适应描述符、神经网络能量模型、基于阶梯的训练、不确定性量化以及通过蒙特卡洛采样进行的有限温度模拟。它基于 PyTorch 和 pymatgen 库构建，支持多个子晶格上具有多种物种的系统，并在图形处理单元上运行。我们在两种材料系统上演示了该软件包。第一个模型中，跨越 9 组分耐火合金的整个成分空间的单一模型解决了短程有序和有序-无序行为。该模型能够快速筛选具有强 Cr 聚集的成分，该特征与连续、耐腐蚀氧化物鳞片的形成有关。第二个模型中，Mo-Nb-W 合金中的氢溶解模型再现了氢吸收的成分依赖性，并解决了氢占据的间隙环境。 pyeCE 的模块化设计使其能够扩展到合金热力学之外的问题，包括动力学、缺陷能量学以及化学顺序与磁和振动自由度的耦合。
