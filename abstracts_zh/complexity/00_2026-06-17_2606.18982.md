# 通过随机场自旋链中的乱序相关器探测混沌和热化

- **arXiv**: [2606.18982](https://arxiv.org/abs/2606.18982)
- **日期**: 2026-06-17
- **分类**: complexity
- **作者**: C Jisha, Shivam Mishra, Ravi Prakash
- **NOFX相关度**: 0

## 摘要

乱序相关器 (OTOC) 已成为多体系统中信息扰乱和量子混沌的诊断方法。我们研究了具有随机场的海森堡自旋 $1/2$ 链中 OTOC 动力学中的混沌印记。该系统被参数化以表现出从可积动力学到混沌动力学的交叉。我们通过数值证明了 OTOC 的饱和方法可以区分可积系统和混沌系统，可积系统具有幂律 $(1/t)$ 松弛，而混沌系统则具有更高程度的幂律衰减 $(1/t^α; α\ge 1)$，然后是指数松弛。我们进一步表明，长程光谱统计数据（例如数量方差）在表征 OTOC 接近饱和状态下的量子混沌时更有效。我们还证明了松弛和初始置乱机制表现出独特且普遍的特征，前者是敏感的，后者对随机场的不同实现具有鲁棒性。 OTOC的长时间饱和度也会随着不同的实现而波动，其精确表达式是通过本征态热化假说推导出来的。
