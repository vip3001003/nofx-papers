# 量子图灵模式的动物学

- **arXiv**: [2608.20151](https://arxiv.org/abs/2608.20151)
- **日期**: 2026-08-20
- **分类**: complexity
- **作者**: Kazuki Ikeda
- **NOFX相关度**: 0

## 摘要

我们探索量子图灵模式动物学，其中相同的 Lindblad 方程支持条纹、斑点、孔、迷宫和缺陷的形态图谱。稳定的条纹种类提供了一种定量控制的情况，其中形态和高斯见证损失参数分离。特别是，在完全正 Lindblad 晶格中与相同 $k_*$ 模式相关的两个高斯见证边际过零后，可见的图灵条纹可以保留。确切 shell 上的见证阈值为 $\mathcal{N}^{-1}$。在固定晶格尺寸、时间窗口和形态标准下，条纹向列阈值趋向于非零值。因此，形态阈值与任一见证阈值的比率随着 $\mathcal{N}$ 的增加而增长。成像和动量分辨协方差测量分别探测这些扇区。
