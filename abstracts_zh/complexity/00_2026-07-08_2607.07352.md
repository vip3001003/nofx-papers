# 用于生物分子排列、聚类和域识别的 RMSD 之外的距离度量的贝叶斯学习

- **arXiv**: [2607.07352](https://arxiv.org/abs/2607.07352)
- **日期**: 2026-07-08
- **分类**: complexity
- **作者**: Saumyak Mukherjee, Gerhard Hummer
- **NOFX相关度**: 0

## 摘要

均方根偏差 (RMSD) 是分子动力学 (MD) 模拟中结构比较的标准度量。在其传统形式中，RMSD 为所有原子分配相同的权重，无论迁移率如何。因此，灵活的循环和无序区域可以主导全局 RMSD，而刚性的功能核心对整体指标的贡献可以忽略不计。为了解决这个问题，我们引入了贝叶斯最优 RMSD（BRMSD），它通过最大化贝叶斯后验来联合优化每个原子权重和结构平均值。在低 RMSD 和重量均匀性之间的权衡中，位置波动参数 $σ$ 控制从经典 RMSD ($σ\to \infty$) 到逐渐聚焦于刚性核心 ($σ\to 0$) 的过渡。 BRMSD 框架支持结构对齐、集中对齐到用户指定域、轨迹平滑、软 $K$ 意味着构象聚类和刚性域识别的分析模块。这些模块在开源 Python 包 BRMSD (https://github.com/bio-phys/BRMSD) 中实现，并在两个 MD 系统（内质网易位子相关蛋白 SND3 和磷酸转移酶腺苷酸激酶）上进行基准测试。
