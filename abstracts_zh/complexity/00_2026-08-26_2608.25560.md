# 带锚节点的超图上的 $(k,n)$-核心渗透

- **arXiv**: [2608.25560](https://arxiv.org/abs/2608.25560)
- **日期**: 2026-08-26
- **分类**: complexity
- **作者**: Hoseung Jang, Byungjoon Min, Ginestra Bianconi
- **NOFX相关度**: 0

## 摘要

超图描述涉及多个节点的高阶交互。超图的一个特征是其鲁棒性会受到节点不同角色的强烈影响。事实上，某些节点可能对于超边缘的功能至关重要，而其他节点则可能不是。单个必要节点的丢失会完全破坏其所属的超边，而非必要节点的丢失则具有缓冲作用，导致超边简单地减小其大小。为了捕捉这种现象，我们为超图上的 $(k,n)$ 核心渗流模型制定了一个全面的理论框架，其中超边的每个节点都是概率为 $θ$ 的锚，如果锚节点失败，则超边也会失败。超图$(k,n)$核心渗滤问题可以分为第一邻居问题和第二邻居问题，表明在剪枝过程中，连通性仅由第一邻居或第二邻居的状态分别保证。我们推导出第一邻居和第二邻居（基于节点和超边）剪枝过程的自洽方程，并获得巨型 $(k,n)$ 核心的大小。我们获得了相图，包括连续和不连续的转变，并使用数值模拟证实了我们关于随机超图的理论。结果表明，节点功能角色的异质性和交互范围的扩展如何影响高阶网络的鲁棒性。
