# 改进的面向汽车的随机交通流模型平均场理论

- **arXiv**: [2608.04731](https://arxiv.org/abs/2608.04731)
- **日期**: 2026-08-05
- **分类**: complexity
- **作者**: Yasar Efe Dai, Andreas Schadschneider, Michael Schreckenberg
- **NOFX相关度**: 0

## 摘要

我们提出了一种改进的单车道车辆交通元胞自动机模型的平均场分析。通过结合之前已成功应用于类似模型的面向汽车的平均场 (COMF) 理论和 2 站点聚类方法的各个方面，我们的目标是更准确地捕获短期和长期相关性。与经典平均场理论相比，改进的方法非常适合具有非均匀稳态的模型，并且能够捕获相分离的基本属性，例如在具有慢启动规则的模型中。通过 $v_{\text{max}}=1$ 的 VDR 模型的应用说明了改进的准确性和新的物理见解。
