# An Absorbing State Model with an Emergent Ising Transition

- **arXiv**: [2610.03936](https://arxiv.org/abs/2610.03936)
- **日期**: 2026-10-02
- **分类**: complexity
- **作者**: Shen Ai, Dov Levine, Paul Chaikin
- **NOFX相关度**: 2

## 摘要

We study a dynamical model of repulsive needles with centers fixed on a square lattice. Needles that overlap are active and receive a repulsive rotation $ θ\in [0,ε)$; needles with no overlap do not move. This model exhibits an absorbing state transition. Nematic order was observed for long needles. For a range of needle lengths and $ε$, the system self-organizes into a state with checkerboard symmetry. As $ε$ is increased, this phase melts and becomes disordered. Remarkably, we find that this phase boundary exhibits critical exponents identical to those of the equilibrium 2D Ising model.
