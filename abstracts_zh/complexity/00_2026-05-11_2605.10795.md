# 线性联想记忆中的事实回忆：敏锐的渐近论和机械见解

- **arXiv**: [2605.10795](https://arxiv.org/abs/2605.10795)
- **日期**: 2026-05-11
- **分类**: complexity
- **作者**: Alessio Giorlandino, Sebastian Goldt, Antoine Maillard
- **NOFX相关度**: 0

## 摘要

大型语言模型在事实记忆方面表现出卓越的能力，但存储和检索神经网络输入输出关联的基本限制仍不清楚。我们在最小设置中研究这些限制：线性关联存储器，通过单层将 $\mathbb{R}^d$ 中的 $p$ 输入嵌入映射到相应的~$d$ 维目标，要求每个映射的输入与所有其他目标很好地分离。与监督分类不同，这种严格的分离会导致每个关联产生约 $p$ 约束，并在约束之间产生很强的相关性，这使得直接表征存储容量变得困难。在这里，我们通过以下方式提供这种能力的精确表征。我们首先引入一个解耦模型，其中每个输入都有自己独立的一组竞争输出，并提供数值和分析证据，证明该解耦模型在存储容量、学习权重谱和存储机制方面与原始模型等效。使用统计物理学的工具，我们表明解耦模型可以存储最多 $p_c \log p_c / d^2 = 1 / 2$ 关联，并将 $p_c$ 的计算推广到线性两层架构。我们的分析还提供了关于最佳解决方案如何改进朴素赫布学习规则的机制：最佳解决方案不是通过广泛的波动来提高输入输出对齐，而是将正确分数提高到略高于竞争输出设置的极值阈值。这些发现给出了线性网络中事实存储的清晰的统计物理特征，并为理解更现实的神经架构的存储容量提供了基线。
