# 受挫的伊辛环的数字技术：反非绝热术语的作用

- **arXiv**: [2607.23074](https://arxiv.org/abs/2607.23074)
- **日期**: 2026-07-25
- **分类**: complexity
- **作者**: Kiran Thengil, Vincenzo Roberto Arezzo, Giuseppe E. Santoro
- **NOFX相关度**: 0

## 摘要

我们研究了局域反绝热（CD）项在增强受挫伊辛环离散时间数字协议性能方面的作用，伊辛环是一个具有指数级小光谱间隙的系统，是传统量子退火的瓶颈。研究的技术范围从固定时间表协议的数字化版本（包括最低阶分析 CD 项）一直到成熟的量子近似优化算法 (QAOA)，包括变分 CD 项 (DC-QAOA)。通过分析所得的剩余能量，我们表明 DC-QAOA 与斩波随机基础 (CRAB) 量子控制技术相结合来优化电路参数，可以优于所有其他策略。通过监测动态过程中的基态布居，我们了解到 DC-QAOA 通过中间激发态找到了通往目标态的有效捷径，这一过程通过包含局部 CD 酉而意外得到增强。我们的结果强调了 CD 动力学的灵活变分控制的重要性，并证明数字优化可以探索标准分析 CD 结构仍然无法访问的操作员动力学。
