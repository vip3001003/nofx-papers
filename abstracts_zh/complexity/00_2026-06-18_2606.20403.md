# 电荷 1/3 任意子流体中的超导性和非费米液态金属

- **arXiv**: [2606.20403](https://arxiv.org/abs/2606.20403)
- **日期**: 2026-06-18
- **分类**: complexity
- **作者**: Zhengyan Darius Shi, T. Senthil
- **NOFX相关度**: 0

## 摘要

我们重新审视通过掺杂 $ν= 2/3$ Jain 分数陈绝缘体 (FCI) 获得的电荷 1/3 任意子流体。在标准复合费米子描述中，掺杂的任意子分成三种与平移相关的次级复合费米子风味，其规范介导的相互作用驱动了强大的风味间配对不稳定性。在我们之前的工作中，我们分析了风味不对称配对态并获得了电荷有序的费米液体。受最近一篇论文的启发，我们考虑了另一种风味对称配对状态，并证明它是 SC* 状态：与剩余 $\mathbb{Z}_2$ 拓扑顺序共存的电荷 $2e$ 凝聚态。弱和强配对机制具有相同的内在拓扑顺序，但手性中心电荷不同，给出 $c_- = 7/2$ 和 $c_- = 2$。我们进一步展示了其他提出的有效场论如何适应相同的复合费米子描述，并认为在掺杂驱动的 FCI 到超导体的转变中，局域任意子演化为 Bogoliubov 准粒子而不是涡旋。在低掺杂下，我们确定了一个近似的 SU(3) 对称体系，其中系统实现了具有三个电荷 1/3 费米子口袋且没有尖锐电子准粒子的非费米液体 $\mathbb{Z}_3$ 正交金属。最后，我们评论了各种可能的基态的能量学，并讨论了对莫尔材料实验的影响。
