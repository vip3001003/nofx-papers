# 表示流的多尺度一致性

- **arXiv**: [2605.26412](https://arxiv.org/abs/2605.26412)
- **日期**: 2026-05-26
- **分类**: complexity
- **作者**: Amir Jafari
- **NOFX相关度**: 0

## 摘要

非线性和统计物理中的许多问题都是通过表示流来表述的，包括物理空间矢量场、相空间漂移场和截断重正化群 beta 函数。我们引入了一种补充性的依赖于表示的诊断，用于测试有限分离流几何在观测分辨率上是否稳定。对于两个分离的点、状态或理论，该方法在场以两种分辨率平滑后比较相应的矢量场增量的方向。对采样分离的归一化比较进行平均，得到与所选变量、粗粒度、度量和采样协议相关的相干矩阵；它是一致性检验，而不是坐标不变量。我们在三种设置中演示诊断。然而，具有相同傅立叶振幅、频谱和标量两点相关性的合成无散度场会产生不同的相干矩阵，这表明二阶统计量并不能确定交叉分辨率增量几何形状。洛伦兹相空间测试表明，平滑的坐标起皱变化代表了漂移几何形状，而不会改变底层动力学，并且即使局部拉伸代理保持紧密匹配，弱模型扰动也会降低有限分离相干性。最后，对于三维 \(O(1)\) 标量理论的函数重正化群流，投影 \(M=4,5,6\) LPA beta 场保持内部相干，而交叉截断相干性随着高阶耦合方向的激活而降低。该诊断提供了对表示、模型和截断如何保留有限分离流几何形状的实用现场级检查，补充而不是取代标准局部、谱或定点诊断。
