# 高熵合金中短程序的可微逆设计：从目标 sro 到目标性能

- **arXiv**: [2607.02219](https://arxiv.org/abs/2607.02219)
- **日期**: 2026-07-02
- **分类**: complexity
- **作者**: Tiancheng Ding, Conrard Giresse Tetsassi Feugmo
- **NOFX相关度**: 0

## 摘要

短程有序 (SRO) 控制多主要元素合金的机械响应，但针对目标性能设计合金通常意味着解决两个互不相关的问题：构建与所需 SRO 模式匹配的结构，然后单独检查其性能，而不进行共享优化。这项工作用基于梯度的方法取代了标准的随机交换搜索（反向蒙特卡罗）：原子占用被视为连续而不是固定，因此可以使用梯度下降来调整整个过程，这与训练神经网络的方法相同。该构建器在小型系统上与随机交换精度相匹配，但在大型 4000 个原子系统上速度提高了六倍，精度提高了八倍，并且可以平滑地扩展到具有许多元素的合金，而无需额外的簿记。基于物理的修正项改编自之前的二元工作，并在此处扩展到许多元素，使设计的结构保持热力学真实性，而不仅仅是在数字上匹配目标 SRO 模式。然后，小型神经网络直接根据成分和 SRO 统计数据预测机械性能，从而形成从目标性能到结构的闭环。该管道在九种面心立方和体心立方合金上进行了测试，捕获了 SRO 驱动的刚度从 -20% 到 +57% 的变化，并且单元尺寸检查显示至少需要 864 个原子才能获得这些变化的方向和尺寸，因为常用的 108 个原子单元可能会产生误导。与钴铬镍合金的实际模拟相比，该方法将四个目标刚度值中的三个匹配在 6% 以内。该方法作为开源 Python 包 anisro 发布，为基于梯度、属性驱动的合金设计提供了实用途径。
