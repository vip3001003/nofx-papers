# 约束 Tsallis 修正对正负电子湮灭造成的光子再加热

- **arXiv**: [2605.03223](https://arxiv.org/abs/2605.03223)
- **日期**: 2026-05-04
- **分类**: complexity
- **作者**: Matias P. Gonzalez
- **NOFX相关度**: 0

## 摘要

在这项工作中，我们概括了早期宇宙中从电子-正电子湮灭到光子的熵转移。通过使用从 Curado-Tsallis 约束导出的广义分布函数，在 Tsallis 形式中实现了泛化。通过这种变形，电磁扇区的熵密度被修改，同时光子分量保持广泛。因此，仅在 $e^-e^+$ 对中引入非扩展校正。这会影响正负电子湮灭之前的熵自由度，从而改变温度比 $T_ν/T_γ$。然后将所得校正映射到相对论物种的有效数量 $N_{\rm eff}$。最后，通过使用 CMB$+$BAO 和 BBN 数据执行组合 $χ^2$ 分析，我们获得非广延参数的 $2σ$ 边界 $|q-1|\leq 1.3\times10^{-2}$。这一结果意味着，在 MeV 时代，玻尔兹曼-吉布斯广延性的任何偏离或修正都必须保持很小。
