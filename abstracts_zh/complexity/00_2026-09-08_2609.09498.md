# Gap-controlled thermalization in a SSH model version of the Fermi-Pasta-Ulam-Tsingou chain

- **arXiv**: [2609.09498](https://arxiv.org/abs/2609.09498)
- **日期**: 2026-09-08
- **分类**: complexity
- **作者**: José A. Aké, Gerardo G. Naumis
- **NOFX相关度**: 0

## 摘要

在经典非谐晶格中，驱动非线性模式混合的共振结构由带隙重塑。然而，目前尚不清楚光谱间隙是否会阻碍或促进长时间热化。在这里，我们研究了二聚化的 Fermi-Pasta-Ulam-Tsingou 链（一种具有交替弹簧常数的经典 SSH 模型类似物），并量化了声光间隙如何在 α 型（三次）非线性下控制弛豫。通过长时间的辛模拟跟踪模态能量和谱熵，我们发现当二聚强度达到其最大值的一半时，会出现一个尖锐的隔离阈值，该阈值是由第一个 umklapp 过程的开始设定的，该过程允许两个区域边界声学声子融合成区域中心光学声子；低于该阈值，三波声-声-光散射会在 1e4 阶振荡周期的时间尺度上激活光分支，而高于该阈值时，频带保持动态隔离。我们进一步表明，边界条件重塑了这幅图景，为特定模式激发产生了长寿命的粘性态。这些结果将声子能隙确立为非线性能量传输的可调谐、动量选择性滤波器，提出了控制二聚或拓扑有隙非线性晶格中热化的一般途径。
