# TempLat：用于晶格场论的多功能 C++ 引擎

- **arXiv**: [2607.24908](https://arxiv.org/abs/2607.24908)
- **日期**: 2026-07-27
- **分类**: complexity
- **作者**: Adrien Florio, Franz R. Sattler
- **NOFX相关度**: 0

## 摘要

我们提出了 TempLat，一个用于任意维度晶格场论模拟的 C++ 框架。其符号语言基于表达式模板构建，可在从经典统计到蒙特卡罗模拟的各种环境中将数学表达式几乎逐字转换为 C++，同时编译为高度优化的内核。 TempLat 具有性能可移植性：基于 Kokkos 构建，它支持大型 CPU 集群以及 NVIDIA 和 AMD GPU。它将硬件抽象为设备概念，使得 TempLat 可扩展到未来的架构。我们在 CPU 和 GPU 上展示了出色的强扩展和弱扩展。我们还推出了 ParaFaFT，一个独立的并行离散傅立叶变换库，支持上述所有硬件上的任意维度，并对其缩放进行了基准测试。两者都是开源的，可在 GitHub 上获取，并为新版本的 CosmoLattice 提供支持，CosmoLattice 是一种广泛使用的早期宇宙模拟库，现已可在 GPU 上使用。
