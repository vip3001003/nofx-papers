# 受抑场：二维流形上受抑布朗粒子的统计场论

- **arXiv**: [2605.05366](https://arxiv.org/abs/2605.05366)
- **日期**: 2026-05-06
- **分类**: complexity
- **作者**: Igor Halperin
- **NOFX相关度**: 0

## 摘要

我们开发了一种统计场论，描述了在紧致二维黎曼流形上具有淬火随机成对相互作用的布朗粒子系统的大 N 极限。由此产生的受挫场 (F2) 模型是流形上平滑自相互作用密度场 $ρ$ 的非线性场论，具有自旋玻璃动力学的局部和非局部（在空间和时间上）自相互作用特征。粒子模拟显示 \emph{绝热降维}：在 $S^2$ 上，密度集中在一个缓慢进动的大圆环上，其方向为指向矢（$\hat{\mathbf{n}} \sim -\hat{\mathbf{n}}$，偶轮廓）。以该模拟支持的环鞍以及慢速方向和带隙密度涨落之间的玻恩-奥本海默分离为条件，对称性将低能动力学固定为实际射影平面 $S^2/\mathbb{Z}_2 = \mathbb{RP}^2$ （射影转子空间上的 $\mathbb{RP}^2$ NLSM） $(0+1)$ 上的非线性 sigma 模型 (NLSM)维度，由单个低能量常数旋转扩散系数 $D_{\text{rot}}$ 控制。通过 $D_{\text{rot}}$ 和通过粒子模拟测量的静环轮廓 $f_0$，所得的有效理论再现了多个独立的方向和密度扇区诊断，无需进一步调整参数。
