# 分子液体中振动强耦合增强瑞利散射介观Ginzburg-Landau模型

- **arXiv**: [2607.15497](https://arxiv.org/abs/2607.15497)
- **日期**: 2026-07-16
- **分类**: complexity
- **作者**: Wenxiang Ying, Abraham Nitzan
- **NOFX相关度**: 0

## 摘要

Sandeep \textit{et al.} 最近的实验 [Angew.化学。国际。埃德。 65, e16917 (2026)]表明分子液体中的振动强耦合（VSC）可以产生超出单分子可观察量的介观现象，包括共振增强瑞利散射、突变浓度阈值和热塌陷。受这些观察的启发，我们构建了一个具有两个耦合场的介观Ginzburg-Landau模型：空腔控制的集体振动极化$P$和次级结构场$m$，其长波长磁化率由集体振动极化强度$P^2$重新归一化，假设控制长波长密度/介电涨落。通过校准参数，该模型捕获了观察到的瑞利增强、集体标度关系和类阈值行为，同时解释了为什么当瑞利散射消失时极化/红外特征可能持续存在。该模型进一步预测了强瑞利增强区域中增强的长波长密度/介电相关性、扩大的介观相关长度以及减慢的结构动力学，通过小角度 X 射线/中子散射和动态光散射探针提供直接的实验测试。
