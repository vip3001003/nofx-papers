# 粒子碰撞量子模拟的状态准备和检测

- **arXiv**: [2607.26142](https://arxiv.org/abs/2607.26142)
- **日期**: 2026-07-28
- **分类**: complexity
- **作者**: Federica Maria Surace, Sary Bseiso, John Preskill
- **NOFX相关度**: 0

## 摘要

模拟粒子碰撞的实时动力学是量子模拟器的一个有前途的应用，因为张量网络等经典方法很难捕获高能散射中产生的高度纠缠态。实现这种模拟需要准备传入波包和检测传出散射产物。在这项工作中，我们提出了解决可编程模拟和数字量子模拟平台挑战的协议。我们的状态准备方案使用弱耦合辅助量子位（或者更一般地说，定制的局部淬灭）来注入具有明确动量的单个准粒子。由于该方案仅依赖于能量守恒，因此不需要微调或有关粒子本征态的先验知识，从而使其能够抵御校准和实施中的错误。然后，仅使用局部测量，从粒子在系统边界反射时产生的干涉图案中提取散射产物的动量。我们通过数值模拟验证我们的协议，首先在一个简单的单粒子模型中，然后在两个相互作用的多体系统中：混合场中的里德堡原子链和伊辛链。我们演示了如何通过绝热斜坡达到非弹性散射过程所需的高能状态，以及如何通过空间调制哈密顿量来优化波包形状。最后，我们展示了如何将该协议推广到具有多个空间维度的系统。我们的建议为散射现象的量子模拟提供了一种通用的方法，并且与已经在实验中可用的几种量子模拟平台兼容。
