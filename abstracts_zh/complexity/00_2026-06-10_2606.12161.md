# 扩散模型中的路径收敛

- **arXiv**: [2606.12161](https://arxiv.org/abs/2606.12161)
- **日期**: 2026-06-10
- **分类**: complexity
- **作者**: Roi Holtzman, Roman Beauvallet, Werner Krauth
- **NOFX相关度**: 0

## 摘要

我们讨论仅通过 p 个模式已知的目标分布与可采样的参考分布之间插值的扩散模型路径。这些内插路径可以对称地构造，或者以从目标图案到参考分布的前向方向（通常称为“噪声”）或者从参考分布到图案的后向方向（称为“去噪”）构造。对于具有相同扩散噪声的后向路径，我们考虑模式数 p 向无限多个模式的路径的路径收敛。在一维测试用例中，我们表明这种收敛的尺度为 1/sqrt(p)，但具有无限均方偏差。我们证明路径收敛允许外推到对目标分布进行采样的 p=无穷大路径。我们提供了一种概念验证外推算法，并提出路径的收敛和外推作为密度估计和泛化的可能策略。我们通过伪代码说明我们所有的算法并提供 Python 实现。
