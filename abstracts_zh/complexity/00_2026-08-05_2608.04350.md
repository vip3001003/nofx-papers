# 对称投影吉布斯态的量子化拓扑不变量

- **arXiv**: [2608.04350](https://arxiv.org/abs/2608.04350)
- **日期**: 2026-08-05
- **分类**: complexity
- **作者**: Weiguang Cao, Haruki Watanabe
- **NOFX相关度**: 0

## 摘要

我们研究投射到可收缩一式对称对称扇形上的吉布斯态。在三维簇模型插值中，该投影稳定了对称保护的拓扑相和投影顺磁相，这两者都与热无序截然不同。通量扭曲膜不变量分别通过值 $-1,+1,0$ 来区分这三个阶段。这些值在端点、自对偶、零温度和无限温度线上是精确的；在其他地方，它们的量子化需要正的空间片、缠绕线和界面张力。量子蒙特卡罗支持通过张力诊断和直接有限大小估计进行量化。
