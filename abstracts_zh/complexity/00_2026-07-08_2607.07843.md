# 自主工作的波动定理

- **arXiv**: [2607.07843](https://arxiv.org/abs/2607.07843)
- **日期**: 2026-07-08
- **分类**: complexity
- **作者**: Christopher Jarzynski, Sebastian Deffner, Saar Rahav
- **NOFX相关度**: 0

## 摘要

功的经典涨落定理已在非自主框架内从理论上获得并通过实验得到验证，在该框架中，通过外部操纵功参数（例如活塞的位置）在感兴趣的系统 ${\cal S}$ 上执行功。在这里，我们在一个自治框架内获得涨落定理，其中 ${\cal S}$ 与可逆功源 ${\cal R}$ 交换能量。这两个子系统 ${\cal R}$ 和 ${\cal S}$ 在哈密顿或随机动力学下演化时彼此相互作用，无需外部干预。在此设置中，我们必须考虑 ${\cal S}$ 对 ${\cal R}$ 的反作用，这在非自主设置中不存在。我们获得了功和熵产生的标准涨落定理的自主版本。我们认为，在每种情况下，当 ${\cal R}$ 的惯性变得无限大时，自主涨落定理就会简化为非自主涨落定理。
