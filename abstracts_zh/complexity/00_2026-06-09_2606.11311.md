# 超越最近邻双酉Floquet系统的精确纠缠动力学

- **arXiv**: [2606.11311](https://arxiv.org/abs/2606.11311)
- **日期**: 2026-06-09
- **分类**: complexity
- **作者**: Tanay Pathak
- **NOFX相关度**: 0

## 摘要

使用对偶幺正性的精确结果很大程度上依赖于最近邻结构，而有限范围的相互作用通常会导致复杂化。超越通常的最近邻设置，我们引入了一个分析上易于处理的有限范围踢伊辛模型系列，该模型承认精确的封闭形式纠缠动力学。该结构基于交错结构，其中子晶格具有对偶统一性，然后彼此耦合。中心观察是这些子晶格间的耦合不会妨碍所得模型的对偶统一性。对于 $r= 2$ 的最小相互作用范围，我们始终导出所有 $n-$Rényi 纠缠熵的精确表达式，并表明结果是两个耦合子晶格贡献的总和。我们的框架自然地扩展到更大的有限交互范围和具有异构局部希尔伯特空间的系统，而无需额外的假设。因此，它为研究超越严格最近邻双酉模型的精确纠缠增长提供了受控环境。
