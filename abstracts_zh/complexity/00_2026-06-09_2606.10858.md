# 稠密流体中动量传递的热力学方法

- **arXiv**: [2606.10858](https://arxiv.org/abs/2606.10858)
- **日期**: 2026-06-09
- **分类**: complexity
- **作者**: Christopher Devik Fjeldstad, Jonas Bueie, Astrid S. de Wijn
- **NOFX相关度**: 0

## 摘要

我们提出了一个新的框架，将查普曼-恩斯科格理论扩展到硬球流体模型之外。该方法不依赖于有效的硬球直径，而是利用与系统的热力学性质相关的交换函数。我们证明了两个现有的扩展，包括修正的恩斯科格理论（MET），适合这个新框架。基于我们的方法，我们提出了 MET 的替代方案，该方案考虑了与流体中颗粒间相互作用相关的潜在相互作用能。所提出的表达式适用于预测多种不同模拟流体模型的剪切粘度，范围广泛，密度为 $0.05 \leq ρ^* \leq 0.8$，温度为 $1.5 \leq T^* \leq 4.0$（以 Lennard-Jones 单位表示）。考虑的流体模型包括 Weeks-Chandler-Anderson (WCA) 流体和 Lennard-Jones (LJ) 流体。在低密度和中密度下，这里取为 $ρ^* \leq 0.3$，我们报告这两者的平均相对预测误差在 $2\%$ 和 $4\%$ 之间。在考虑的所有密度中，WCA 流体和 LJ 流体报告的最大平均相对误差分别为 $4.4\%$ 和 $8.1\%$。我们还研究了其他相互作用模型，包括双原子分子模型，以便更好地理解我们方法的局限性。
