# 具有集体耗散的 N 量子位海森堡链中的无阻尼模式

- **arXiv**: [2607.02054](https://arxiv.org/abs/2607.02054)
- **日期**: 2026-07-02
- **分类**: complexity
- **作者**: Chun Hei Leung
- **NOFX相关度**: 0

## 摘要

我们通过集体自旋跳跃算子研究了自旋 1/2 海森堡链与环境耦合的无阻尼行为。使用 Bethe ansatz 基础，我们表明对于任何链长度 N >= 3 都存在无阻尼模式。这些模式对于系统参数的变化保持鲁棒性，包括集体耗散的特定形式和外部场。利用 Bethe ansatz 解，我们进一步表征了无阻尼模式的数量及其振荡频率，揭示了开放可积量子系统中长寿命的相干动力学。
