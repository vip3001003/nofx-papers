# 从素数的上同调结构中得出的迭代映射

- **arXiv**: [2605.17622](https://arxiv.org/abs/2605.17622)
- **日期**: 2026-05-17
- **分类**: complexity
- **作者**: Marzena Ciszak
- **NOFX相关度**: 0

## 摘要

素数出现在统计力学、量子力学和动力系统的背景下。然而，控制序列中观察到的不规则性并将其与物理系统联系起来的机制仍不清楚。这里表明，不同间隔距离处的素数间隙遵循取决于该距离的函数，并且可以通过预测连续素数的初级增长的迭代图来描述。另一方面，对剩余波动的分析揭示了明确定义的上同调结构的存在，其中确定性函数关系对于素数直至小的衰减波动都成立。因此，素数中的长程相关性和局部跳跃编码了底层的上同调结构，其中素数是给定系统的状态，该系统逐渐变得确定性。值得注意的是，这个上同调方程的解是对数积分函数。
