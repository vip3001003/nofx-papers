# 随机正则图中的偏心率分布

- **arXiv**: [2607.14799](https://arxiv.org/abs/2607.14799)
- **日期**: 2026-07-16
- **分类**: complexity
- **作者**: Dor Lev-Ari, Ofer Biham, Eytan Katzav
- **NOFX相关度**: 0

## 摘要

我们推导出随机正则图 (RRG) 中偏心率分布 (DoE) 的封闭式解析表达式，该随机正则图 (RRG) 由 $N$ 个 $c$ 度的节点组成。 DoE 由尾部分布 $P(E > \ell) \simeq 1 - \exp \left[ - \exp \left( - \frac{ e^{b \ell} - μ}β \right) \right]$ 给出，其中距离 $\ell$ 取整数值，$b = \ln (c-1)$ 是形状参数，$β= \frac{c-2}{c} N$ 是尺度参数，$μ= \frac{c-2}{c} N \ln N$ 是位置参数。通过提供完整的分布而不是单一的特征长度尺度，我们呈现了大规模结构的详细视图。尽管所有节点的度数相同，但它们的偏心率却表现出不小的变化。我们推导出平均偏心率的封闭式表达式，由 $\langle E \rangle \simeq \frac{\ln N}{\ln (c-1)} + \frac{\ln \ln N}{\ln (c-1)} - \frac{ \ln c - \ln (c-2) }{ \ln (c-1) } + \frac{1}{2}$ 给出。我们计算 DoE 的模式，它呈现出作为网络大小函数的阶梯轮廓。有趣的是，模式由 $E_{\rm mode} ={\rm Round} \left( \langle E \rangle \right)$ 给出，其中 ${\rm Round}( x )$ 是最接近 $x$ 的整数。我们还计算方差 ${\rm Var}(E)$ 并表明它表现出作为网络大小 $N$ 的函数的振荡。本文提出的结果可以作为大型稀疏网络中偏心率计算算法方法的基准。偏心率在广播和全球传播等实际应用中很重要，其中网络性能由最长延迟时间决定。
