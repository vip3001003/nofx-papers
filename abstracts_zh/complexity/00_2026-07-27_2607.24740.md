# 对称性丰富的拓扑相中的任意子凝聚：$G$-多重融合类别的分级

- **arXiv**: [2607.24740](https://arxiv.org/abs/2607.24740)
- **日期**: 2026-07-27
- **分类**: complexity
- **作者**: Nianrui Fu, Siyuan Wang, Yu Zhao et al.
- **NOFX相关度**: 0

## 摘要

尽管任意子凝聚是关联拓扑序的标准机制，但对称性丰富的拓扑 (SET) 相中的任意子凝聚更为复杂，因为凝聚也必须与全局对称性兼容。我们研究了由具有多融合类别输入数据的放大 Hu-Geer-Wu (HGW) 弦网模型描述的 SET 相中保对称任意子凝聚。我们证明了 $G$ 保留凝结的特征是输入多重融合类别的兼容分级，并且该分级构造了子 SET 阶段的多重融合类别输入。为了使这种构造具体化，我们考虑相关数据来自 $G$ 通过 $N$ 的有限群扩展 $E$ 的情况：$E$ 分级融合类别通过传递到商对称性 $G$ 来引入 $G$-SET 输入，并且所得输入自然带有兼容的 $N$ 分级，该分级在保留 $G$ 的同时实现了 SET 阶段内的进一步凝聚。我们使用三个量子双精度示例来说明构造：平凡扩展 $\mathbb{Z}_2\times\mathbb{Z}_2$、非阿贝尔半直积 $S_3$ 和非平凡中心扩展 $\mathbb{Z}_4$。 $\mathbb{Z}_4$ 的例子进一步表明，一旦凝聚态被视为物理相干态，对称分式任意子就不会阻碍对称性保持凝聚态。
