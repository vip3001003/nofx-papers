# 二维 Toda--Arnoldi 对应：全纯 Krylov 几何和反非绝热输运

- **arXiv**: [2608.04850](https://arxiv.org/abs/2608.04850)
- **日期**: 2026-08-05
- **分类**: complexity
- **作者**: Urei Miura
- **NOFX相关度**: 0

## 摘要

尽管阿诺尔迪对一般非厄米哈密顿量的约简产生了上赫森伯格矩阵，而不是厄米兰佐斯理论的三对角形式，但我们表明，封闭的 Toda 扇区在其对角线和次对角线系数中仍然存在。对于固定的有限维哈密顿量和全纯变形的循环状态向量，Krylov Gram 行列式是有限二维 Toda 格的 $τ$ 函数，其 Flaschka 变量与这些 Arnoldi 系数完全一致。因此，Toda 动态关闭了该区域，但没有确定剩余的上 Hessenberg 条目。同一扇区的次对角线部分也具有直接的几何意义：平方次对角线系数决定了全纯 Krylov 子空间的 Fubini-Study 度量和贝里曲率，而与 Arnoldi 分解时丢失的子空间相关的几何量不再被定义。沿着循环区域中的平滑实数路径，阿诺尔迪框架连接进一步提供了精确等谱传输的埃尔米特三对角生成器。当添加到阿诺尔迪矩阵时，该生成器会取消瞬时特征空间之间的转换，并在矩阵可通过非简并谱对角化时实现反非绝热驱动。
