# 量子淬灭后子系统距离的离散幂律衰减

- **arXiv**: [2607.25661](https://arxiv.org/abs/2607.25661)
- **日期**: 2026-07-28
- **分类**: complexity
- **作者**: Bin Sui, Jiaju Zhang
- **NOFX相关度**: 0

## 摘要

我们提出了对无限一维横向场伊辛链中全局量子淬灭后子系统距离衰减的数值研究，使用数学上严格的 Bures 距离 $B_A(t)$ 来量化时间演化约简密度矩阵与其平稳广义吉布斯系综状态的偏差。我们表明，后期衰减遵循离散幂律 $B_A(t) \sim t^{-λ}$，指数 $λ$ 仅限于离散值：$1$、$5/4$、$3/2$、$7/4$、$2$、$5/2$ 以及可能的其他值。具体指数由淬火前和淬火后横向场以及对称激励分数函数 $m_S(\varphi)$ 的属性共同确定，该函数在 $\varphi\in[0,π]$ 上定义，用于表征淬火前哈密顿本征态，包括连续性、边界值和一阶导数边界值等。先前建立的淬火前哈密顿量初始基态的 $t^{-3/2}$ 衰减自然会恢复为这种一般分类的特殊情况。我们的结果揭示了可积量子系统中控制局部平衡动力学的通用离散结构。
