# 扩散限制聚集的精确振幅关系

- **arXiv**: [2607.02216](https://arxiv.org/abs/2607.02216)
- **日期**: 2026-07-02
- **分类**: complexity
- **作者**: Thomas C Halsey
- **NOFX相关度**: 0

## 摘要

几十年来，人们已经知道，扩散限制聚集体的调和测度的多重分形谱的三阶矩与团簇的基础分形维数有关。我们使用基于二维扩散限制聚合 (DLA) 的黑斯廷斯-列维托夫公式的论证，证明了一个更强的联系，将第三矩的通用振幅与簇分形维数连接起来。该参数可用于标准圆形 DLA 以及圆柱体中的 DLA（即具有周期性边界条件）。
